# 重置图标

`reset.png` 使用 [Lucide RotateCcw](https://lucide.dev/icons/rotate-ccw)，遵循 ISC 许可证。完整版权及许可文本保存在 `LICENSE-lucide.txt`。

原始矢量文件为 `lucide-rotate-ccw.svg`；固定的上游版本和来源链接见 `lucide-source.json`。图形路径保持原样，只在导出时设为低对比灰色 `#9ba0a6`、16×16 透明 PNG。

`测试/导出开源图标.cjs` 使用构建环境已有的 Sharp 导出资源。C4D 仅加载 PNG，运行插件不需要 Node.js 或 Sharp。按钮的背景、悬停、按下和禁用状态由 C4D 原生控件处理。
